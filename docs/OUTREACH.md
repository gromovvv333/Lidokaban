# Полуавтомат рассылки в Telegram

Ориентир по фиче «первичное касание». Решения приняты пользователем 2026-09-24,
менять их только по новой просьбе. Отменяет пункт «Автоматическая отправка
сообщений лидам» из `PRD.md`: автоотправки по-прежнему нет, есть полуавтомат.

## Суть

Приложение готовит персональный текст и открывает чат, отправляет пользователь
руками. Никаких userbot-библиотек (Telethon/Pyrogram) и никакой автоотправки:
холодная массовая рассылка незнакомым аккаунтам ведёт к бану номера, а вместе с
ним теряется переписка с теми, кто уже ответил. Кнопку «отправить за меня» не
предлагать.

## Принятые решения

| Вопрос | Решение |
|---|---|
| Кому пишем | Лидам с мобильным номером (`is_mobile=да`) **или** найденным `@username` |
| Текст | Шаблоны пишу я, пользователь правит прямо в приложении |
| Режим UI | По одному лиду, конвейер с кнопкой «Следующий» |
| Учёт | Статусы + напоминание о неответивших через 4 дня |
| Лимит парсинга | Поднят с 25 до 100 (`config.MAX_LEADS`), нужен ввод лимита в GUI |

## Как открывается чат

Механика уже есть в `ui.html` и `app.py`:

- по номеру: `tg://resolve?phone=<digits>`, фолбэк `https://t.me/+<digits>`
- по юзернейму: `tg://resolve?domain=<username>`, фолбэк `https://t.me/<username>`
- открытие через `Api.open_app_link` → `subprocess.run(["open", url])`

Текст подставить в поле ввода Telegram нельзя, `tg://` этого не умеет.
Поэтому текст кладётся в буфер обмена одновременно с открытием чата,
пользователь жмёт вставку и отправку.

Часть мобильных номеров окажется без Telegram — чат не откроется. Такой лид
помечается статусом `нет_тг` и из очереди выбывает, повторно не показывается.

## Данные

Новый файл `~/Documents/ЛидоКабан/outreach.json` рядом с `leads.csv` и
`runs.json` (`config.DATA_DIR`), в `.gitignore`. В `leads.csv` статусы не
писать: он дописывается построчно и переписывать его на каждый клик плохо.

Ключ лида — `run_id` + `phone` (если номера нет, то `run_id` + `name`).

Поля записи: ключ, имя, канал (`phone`/`username`), контакт, статус,
`sent_at`, `replied_at`, номер касания (1 или 2), id использованного шаблона.

Статусы: `новый`, `написал`, `ответил`, `отказ`, `нет_тг`, `пропущен`.

Правила: `ответил` и `отказ` — терминальные, лид больше не всплывает никогда.
`написал` с `sent_at` старше 4 дней и без ответа возвращается в очередь один
раз с касанием 2, после чего уходит в `отказ` молчанием.

## Шаблоны

Файл `templates.json` в `DATA_DIR`, создаётся из дефолта при первом запуске,
чтобы правки пользователя не затирались обновлением приложения.

Подстановки: `{name}`, `{category}`, `{city}`, `{rating}`, `{reviews_count}`.

Зацепка выбирается по данным лида: нет сайта → одна формулировка, низкий
рейтинг → другая, много отзывов и есть сайт → третья. Это не LLM-скоринг, а
выбор шаблона по колонкам, запрет на скоринг из `CLAUDE.md` не нарушается.

Второе касание — отдельный короткий шаблон, не копия первого.

## Интерфейс

Новая вкладка рядом с «📜 Прошлые вылазки», в кабаньей теме. Один лид на
экране: имя, категория, рейтинг, зацепка, редактируемое поле с текстом.

Кнопки: «Скопировать и открыть чат», «Отправил», «Пропустить», «Не отвечает».
Счётчик «осталось N». Источник очереди — выбранный прошлый запуск или все лиды.

Правка текста в поле влияет только на текущего лида. Отдельная кнопка
«сохранить как шаблон» переписывает `templates.json`.

## Что продаём

Телеграм-бот записи для груминг-салонов. Две ценности в тексте КП: запись
вечером и ночью, когда салону ответить некому, и авто-возврат клиента через
6–8 недель напоминанием о стрижке питомца. Мини-апп — отдельная опция, в тексте
упомянут как «можно и без него», чтобы не выглядел обязательным.

## Сделано

- `templates.py` — четыре шаблона, выбор по лиду, подстановка полей
- `outreach.py` — очередь, статусы, правило четырёх дней, список ожидающих
- `storage.load_all_leads` — лиды за всю историю, не только за один запуск
- `app.py` — методы `Api`: очередь, отметки, буфер обмена, шаблоны
- `ui.html` — вкладка «📨 Рассылка», редактор шаблонов, поле лимита лидов
- `config.MAX_LEADS` поднят до 100, в форме есть поле на запуск (1–500)
- `postbuild.sh` копирует в `.app` новые модули

## Открытый вопрос

Шаблоны только на русском. Лиды из нерусскоязычных городов (Дубай, Дананг)
получат русский текст, что бессмысленно. В конвейере видна пометка
«не русскоязычный», но англоязычного набора шаблонов пока нет.

## Проверка

GUI из песочницы не запускается, проверяю `py_compile` и логику `outreach.py`
отдельным скриптом на подставных данных. Реальный прогон конвейера и то, что
`tg://resolve?phone=` открывает нужный чат, проверяет пользователь на `.app`.
